# 🛠 프로젝트 설정 개요

## 셋팅

- **빌드 도구:** Vite

- **패키지 매니저:** pnpm

- **스타일:** Tailwind CSS

- **린팅:** ESLint

- **포매터:** Prettier

- **라우팅:** react-router-dom

- **상태 관리:** Zustand

- **네트워크 (API 통신):** axios

   `학번: 000000`, `비밀번호: 어드민`
